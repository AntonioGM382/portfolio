Product engineering · MCP workflow

SplitPoke

A conversational expense splitter built as an agentic Model Context Protocol server with strict financial logic and social onboarding.

TypeScriptMCP HTTP/SSESQLiteRailway

Agentic architecture

Focused MCP tools expose groups, expenses, balances, and settlement. The model handles intent; the service owns validation, money, and state.

Financial correctness

Integer cents prevent floating-point drift. Equal-split remainders are distributed deterministically.

Debt simplification

Member balances form a debt graph. Netting and greedy matching turn many obligations into a smaller settle-up plan.

Identity and delivery

Poke identity propagates through the request header; SQLite persists state. Containerized Railway delivery uses environment configuration and a /healthz endpoint.

Product loop

A Recipe helps one person create a group, share a join code, and bring friends into the workflow. Product growth is built into the system design.

Technical-lead signal

Clear probabilistic/deterministic boundaries, reproducible money math, persistence, deployment, observability, and user-centered design.
