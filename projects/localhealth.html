Supabase schema and resilient ingestion

biometric_samples

user_id, metric, value, captured_at, source

daily_recovery

date, hrv_baseline, rhr_baseline, score

sleep_sessions

start_at, end_at, efficiency, stages

The ingestion engine normalizes Fitbit payloads, aggregates time windows, and compensates for iOS background execution delays with idempotent timestamps and backfill windows. Vercel Serverless Edge hosts the MCP route while Supabase provides auth and durable PostgreSQL storage.
