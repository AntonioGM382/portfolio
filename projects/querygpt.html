Retrieval-augmented generation

QueryGPT

A Node.js RAG architecture that gives organizational data a semantic retrieval layer without confusing source records with vector representations.

Source and embedding layers

sourceData preserves raw documents and provenance. embeddedData stores vector representations for similarity search. The separation makes refreshes and re-embedding explicit.

Retrieval lifecycle

  1. Normalize the query.
  2. Generate an embedding and retrieve related chunks.
  3. Rank and filter evidence.
  4. Assemble focused context for generation.

Context-window discipline

The Node.js backend orchestrates ingestion, embedding, ranking, and generation while limiting prompts to the most relevant evidence—improving answer quality and controlling token cost.
