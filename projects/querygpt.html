Retrieval-augmented generation

QueryGPT

A Node.js RAG architecture providing semantic retrieval without confusing source records with vector representations.

Source and embedding layers

sourceData preserves raw documents and provenance; embeddedData supports similarity search.

Retrieval lifecycle

  1. Normalize the query.
  2. Retrieve related chunks.
  3. Rank and filter evidence.
  4. Assemble focused context.

Context discipline

The backend orchestrates ingestion, embedding, ranking, and generation while controlling prompt size and token cost.
