QueryGPT

A Node.js RAG architecture for asking useful questions over organizational data without conflating source records with their vector representation.

Node.jsRAGEmbeddingsSemantic Retrieval

Two representations, one source of truth

sourceData preserves raw documents and business meaning. embeddedData stores the vector representation used for similarity search. Keeping the layers separate makes re-embedding, provenance, and data refreshes explicit.

Retrieval lifecycle

  1. Receive and normalize the user query.
  2. Generate a query embedding and retrieve semantically related chunks.
  3. Rank and filter results before assembling context.
  4. Send a focused prompt to the generation model.

Context window discipline

The Node.js backend orchestrates ingestion, embedding, retrieval, ranking, and response generation. Context optimization keeps only the most relevant evidence in the prompt, improving answer quality and controlling token cost while maintaining a clear path back to the underlying source data.
